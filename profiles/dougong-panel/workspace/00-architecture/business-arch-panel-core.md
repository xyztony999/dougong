## 第一部分：文档概述

### 1.1 背景与目标

面板基座（panel-core）是斗拱面板的全模块宿主基座：向上承载前端应用骨架（路由/布局/菜单）与各业务模块页面的统一挂载入口，向下管理面板自身运行配置（panel_config）与部署形态。业务输入来源：idea.md §4.1 M1（骨架部分：go:embed 前端内嵌、安装脚本）、§5.4（面板自身安全：监听/入口路径/HTTPS）、§2 D9（单二进制 + 可审计安装脚本）、D0 需求澄清报告（d0-clarification-panel-core.md，2026-11-12）及其依赖的既有决策 ADR-009（安装脚本每一行可读）、ADR-011/012（部署形态与遥测边界）、ADR-017~020（初始化/认证/会话/审计，归 account-auth）、规则 R-09（零遥测，更新检查默认关）、R-10（默认监听 0.0.0.0:随机高位端口、可选安全入口路径、建议但强制 HTTPS）；增量 D1 输入（2026-11-16）：ADR-028（面板域名绑定=强校验）、ADR-029（面板自身证书 ACME=经已有 nginx HTTP-01，复用 site-mgmt AcmeGateway 与 nginx 安全写回）；CLI 增量 D1 输入（2026-11-16）：ADR-030（面板管理 CLI：`dougong` 子命令族直接操作本机数据目录/SQLite、复用进程内 service 层，无新领域对象/无前端页面）。

本业务架构设计目标：

1. 以 L1-L4 层级刻画面板基座「安装部署 → 访问接入 → 外壳呈现 → 配置与版本治理」的业务全生命周期；
2. 将已拍板的业务规则（R-09 零外呼与更新检查默认关、R-10 监听/入口/HTTPS 入口面、ADR-009 可审计安装脚本）与 D0 待细化项（可配置项全集及生效方式、HTTPS「建议但不强制」口径、菜单挂载点联动）落到确定的业务活动节点上；
3. 为应用架构（AA）与功能清单（FL）提供唯一业务依据。

## 第二部分：业务架构

> 本章按 L2→L3→L4 逐层描述业务架构。每层有其概述和业务说明。

### 本架构概览

面板基座遵循「先装得上、再进得来、再看得见、再管得住」的业务主线，按时间序划分四个业务阶段：

- **安装部署阶段**：以可审计的一键安装脚本（每行可读，ADR-009）交付单二进制（前端 go:embed 内嵌）并由 systemd 托管运行，是面板一切业务的技术起点；交付的二进制同时承载运行期 CLI 管理通道（`dougong` 子命令族，ADR-030），在服务器终端直治面板自身（状态/信息/端口/入口路径/服务控制/管理员密码重置）；
- **访问接入阶段**：治理入站访问的四道入口面——监听地址与端口（默认 0.0.0.0:随机高位端口）、可选安全入口路径、可选面板域名绑定（Host 级强校验，ADR-028）、HTTPS 三态（自签/导入证书/关闭，证书来源含 ACME 签发，建议但不强制）；
- **外壳呈现阶段**：以统一应用骨架（布局/路由/菜单）承载全部业务模块页面，菜单按角色可见性渲染（管理员全量、只读仅查看类），业务模块页面以子路由/菜单项挂载入外壳；
- **配置与版本治理阶段**：以 panel_config 单例为唯一权威治理面板自身配置（配置项全集见应用架构附录C，区分即时生效与需重启生效），透传展示归属其他模块的配置项，并提供版本信息展示与默认关闭的更新检查开关治理。

四阶段为时间序依赖：安装部署产出可运行的面板服务 → 访问接入决定「谁能到达面板」→ 外壳呈现决定「到达后能看到什么」→ 配置与版本治理贯穿运行期持续可治理。跨域依赖：配置变更等变更类操作经 account-auth 审计契约留痕（R-03），菜单可见性消费 account-auth 角色判定（ADR-018），会话参数仅透传展示（维护归 account-auth，ADR-019）。

### 2.1 安装部署阶段

**业务说明**：面板生命周期的业务起点。以「下载二进制 + 生成 systemd unit」的一键安装脚本交付，脚本每一行可读、可审计（ADR-009）；产物为前端资源内嵌（go:embed）的单二进制，无运行时依赖（D9），由 systemd 服务托管常驻运行；该二进制另承载运行期 CLI 管理通道（2.1.1.4，ADR-030）。

##### 2.1.1 安装与部署

**业务说明**：面板交付与常驻运行的业务能力。所属 L2：安装部署阶段。涵盖安装脚本一键安装、systemd 服务托管、单二进制内嵌产物形态与 CLI 管理通道；安装与 CLI 动作均在服务器终端执行，不依赖面板会话。

###### 2.1.1.1 安装脚本一键安装

**业务说明**：以 install.sh 一键完成面板安装：下载二进制、落位程序文件、生成 systemd unit 并启用服务；脚本每一行可读、可人工审计后方执行（ADR-009，产品「可信」承诺的交付面）。所属 L3：安装与部署。

###### 2.1.1.2 systemd 服务托管

**业务说明**：面板进程以 systemd 服务（dougong.service）方式常驻运行，随安装启用开机自启；服务的启停治理属操作系统层，面板自身不提供在线自升级（idea.md §4.2 非目标）。所属 L3：安装与部署。

###### 2.1.1.3 单二进制内嵌产物

**业务说明**：面板交付形态为单一可执行文件：前端静态资源经 go:embed 内嵌，SQLite 单文件存储，无外部运行时依赖（D9/ADR-011）——保证安装面最小、资源占用可控（常驻内存目标 < 60MB）。所属 L3：安装与部署。

###### 2.1.1.4 CLI 管理通道

**业务说明**：服务器终端经 `dougong` 子命令族对面板自身的本地管理通道（宝塔同款定位，ADR-030）：直接操作本机数据目录/SQLite，复用进程内业务能力（单二进制优势，无 HTTP 绕行）——状态查询（systemd 状态+初始化态+访问 URL）、运行信息（版本/端口/入口路径/HTTPS/数据目录）、管理员密码重置（环境变量注入新密码，同初始化口径）、端口设置、安全入口路径查看/重生成/关闭、面板服务启停/重启/状态（systemctl 治理）。读命令在服务运行时可直接读取；写命令完成后提示重启面板服务生效；变更动作记审计（来源=cli，枚举池既有 audit_source）。密码重置的账户业务规则归账户与安全基座（account-auth，与初始化 CLI 子命令同族，ADR-017/030），本域仅承载命令入口与本地执行；本通道无面板页面，裸 `dougong` 仍为启动面板服务。所属 L3：安装与部署。

### 2.2 访问接入阶段

**业务说明**：治理「谁能到达面板」的入口面。四道入口面协同：监听地址与端口决定服务绑定面（默认 0.0.0.0:随机高位端口，可选仅 localhost/指定地址，R-10）；可选安全入口路径为 URL 前缀级门槛（开启后未携带者被拒绝）；可选面板域名为 Host 级强校验门槛（绑定后仅该域名可访问，IP 直连与其他 Host 一律标准 404，ADR-028）；HTTPS 三态为传输层保护（建议但不强制，R-10），面板证书可经 ACME 签发与续期（2.2.2.3，ADR-029）。

##### 2.2.1 监听与入口接入

**业务说明**：面板服务的网络绑定与 URL 级入口门槛治理。所属 L2：访问接入阶段。

###### 2.2.1.1 监听地址与端口治理

**业务说明**：维护面板监听地址与端口：默认监听 0.0.0.0 的随机高位端口（最小暴露，R-10/idea.md §7），可选收紧为仅 localhost 或指定地址；端口变更需重启服务生效。所属 L3：监听与入口接入。

###### 2.2.1.2 安全入口路径管控

**业务说明**：可选的随机 URL 前缀门槛：开启后，未携带安全入口路径的任何访问（含未认证访客）在进入业务前即被拒绝；路径可重新生成，修改即时生效（R-10）。所属 L3：监听与入口接入。

###### 2.2.1.3 面板域名绑定

**业务说明**：可选的 Host 级强校验门槛：在 panel_config 登记绑定域名（可空=未绑定）；绑定后仅该域名的 Host 可访问面板，IP 直连与其他 Host 的一律返回标准 404（不泄露面板存在性，与安全入口路径同防探测语义）；域名校验态读取失败时按失败拒绝（fail-closed，读态不可用即拒）处理；绑定与解绑即时生效（ADR-028）。所属 L3：监听与入口接入。

##### 2.2.2 HTTPS 接入治理

**业务说明**：面板自身传输层保护治理：关闭/自签证书/导入证书三态管理，面板证书来源在自签/导入之外新增 ACME 签发（2.2.2.3，ADR-029），「建议但不强制」——HTTP 访问时首访提示建议、设置页常驻开关（R-10 的 UI 口径，D0 拍板）。站点业务证书不在此列（归 site-mgmt；本域 ACME 签发经跨模块消费复用其签发通道，ADR-029）。

###### 2.2.2.1 HTTPS 三态配置

**业务说明**：管理面板自身 HTTPS：关闭、自签证书（系统生成）、导入证书（上传证书与私钥）三态；切换除关闭外即时生效。所属 L3：HTTPS 接入治理。

###### 2.2.2.2 首访 HTTPS 建议

**业务说明**：以 HTTP 方式访问面板时展示建议启用 HTTPS 的提示；设置页提供常驻 HTTPS 开关——「建议但不强制」的统一 UI 口径（R-10，D0 拍板）。所属 L3：HTTPS 接入治理。

###### 2.2.2.3 面板证书 ACME 签发与续期

**业务说明**：面板自身证书的 ACME 签发与续期业务：以 HTTP-01 挑战经服务器已有 nginx 完成验证（存量服务器 80 端口已被 nginx 占用，不新增独立 80 端口监听），挑战 location 的临时注入与撤除、签发通道均复用网站管理（site-mgmt）的既有能力（安全写回流程与 ACME 签发网关，ADR-029 跨模块消费契约）；证书产物落面板证书，证书来源在自签/导入之外扩展 ACME，HTTPS 模式随之联动；到期前自动续期，失败可手动重试；DNS-01 通配符证书为二期事项。所属 L3：HTTPS 接入治理。

### 2.3 外壳呈现阶段

**业务说明**：登录后所见面板界面的骨架业务：统一布局与路由框架、按角色可见性渲染的导航菜单、以及各业务模块页面以子路由/菜单项挂载入外壳的组织方式。认证页面（登录/初始化向导）的路由亦由外壳承载，认证业务本身归 account-auth。

##### 2.3.1 应用骨架与导航

**业务说明**：面板界面的统一骨架：整体布局与路由注册，以及导航菜单按操作者角色过滤渲染——管理员可见全量菜单，只读角色仅见查看类菜单（ADR-018 只读边界的界面呈现）。所属 L2：外壳呈现阶段。

###### 2.3.1.1 布局与路由骨架

**业务说明**：面板前端应用的整体布局框架与路由注册：承载认证页面路由（登录/初始化向导，业务归 account-auth）与全部业务页面路由的统一容器。页面切换过程对操作者可见：切换开始即有加载反馈；页面文件没下载下来时给出提示并可在下一次点击重试，面板升级后未刷新的旧页面自动重新加载；弹窗、抽屉正在关闭时侧栏照常可点。内嵌的页面文件经压缩传输，已不存在的页面文件如实回 404（v1.3，缺陷反馈「侧栏有时点不动」）。所属 L3：应用骨架与导航。

###### 2.3.1.2 菜单渲染与角色可见性

**业务说明**：导航菜单按操作者角色过滤渲染：管理员全量可见；只读角色仅见查看类菜单、变更类入口不可见（ADR-018）；未认证访客仅达认证页面路由。可见性判定消费 account-auth 的角色边界规则。所属 L3：应用骨架与导航。

##### 2.3.2 模块页面挂载

**业务说明**：各业务模块页面接入外壳的组织方式：以子路由/菜单项为统一挂载点登记接入（挂载点清单见应用架构附录D，随各模块 D1 产出联动）。认证页面（登录/初始化向导）的路由承载亦属本业务，认证业务归 account-auth。

###### 2.3.2.1 业务模块页面挂载

**业务说明**：各业务模块（监控、服务、文件、网站、数据库、终端、防火墙、容器、计划任务与备份等）的功能页面以子路由/菜单项挂载入面板外壳，形成统一操作入口；挂载点清单为模块接入的唯一登记处。所属 L3：模块页面挂载。

###### 2.3.2.2 认证页面承载

**业务说明**：登录页与初始化向导页的路由承载：外壳为其提供页面容器与路由入口，认证业务逻辑（初始化双入口互斥、登录锁定、会话签发）归账户与安全基座（account-auth，ADR-017~019）。所属 L3：模块页面挂载。

### 2.4 配置与版本治理阶段

**业务说明**：面板运行期的自身治理：以 panel_config 单例为唯一权威维护面板自身配置项全集（D0 待细化项，全集与生效方式清单落在应用架构附录C），区分即时生效项与需重启生效项；透传展示归属其他模块的配置项；提供版本信息展示与默认关闭、可完全禁用的更新检查开关（R-09）。全部配置变更属变更类操作，经 account-auth 审计契约留痕（R-03）。

##### 2.4.1 面板配置管理

**业务说明**：panel_config 单例的读写与生效治理：配置项全集（监听地址/端口、安全入口及开关、面板绑定域名、HTTPS 模式与证书、更新检查开关、界面语言等）的维护，保存时按「即时生效/需重启」分类提示，并透传展示归属其他模块的会话参数。所属 L2：配置与版本治理阶段。

###### 2.4.1.1 配置项维护

**业务说明**：维护 panel_config 配置项全集：监听地址/端口、安全入口路径及开关、面板绑定域名、HTTPS 模式与证书、更新检查开关、界面语言等（全集清单与默认值见应用架构附录C）；变更类操作记审计（R-03）。所属 L3：面板配置管理。

###### 2.4.1.2 配置生效与重启提示

**业务说明**：配置保存后的生效治理：区分即时生效项（安全入口、HTTPS、更新检查、语言等）与需重启生效项（监听地址/端口），后者保存后明确提示需重启服务；生效状态在设置页可辨识（D1 判定，见应用架构附录C）。所属 L3：面板配置管理。

###### 2.4.1.3 会话参数透传展示

**业务说明**：在面板设置中透传展示会话有效期策略当前值（绝对过期/空闲超时，ADR-019）；该配置的维护业务与存储归账户与安全基座（account-auth），本域仅提供只读展示入口（D0「会话参数透传显示项」的落位）。所属 L3：面板配置管理。

##### 2.4.2 版本与更新检查治理

**业务说明**：面板版本可观测与更新检查的克制治理：版本信息对外展示；更新检查默认关闭且可完全禁用（R-09 零外呼承诺），开启后仅做版本比对提示，不做在线自升级（idea.md §4.2 非目标）。

###### 2.4.2.1 版本信息展示

**业务说明**：展示面板当前版本号与构建信息（关于页与界面标识），作为版本可观测与排查依据；版本标识随构建内嵌。所属 L3：版本与更新检查治理。

###### 2.4.2.2 更新检查开关治理

**业务说明**：更新检查开关治理：默认关闭、可完全禁用（R-09：程序自身不发起外部请求，除用户主动 ACME 申请）；管理员显式开启后可手动触发一次版本检查，仅提示新版本号、不执行下载或升级；开关变更记审计（R-03）。所属 L3：版本与更新检查治理。

### 附录B：业务术语表

> 统一业务术语定义，后续领域对象命名以此为准。

| 术语 | 定义 | 备注 |
|------|------|------|
| 面板基座（panel-core） | 全模块宿主基座：前端应用骨架与面板自身配置的唯一权威，各业务模块页面以子路由/菜单项挂载 | D0 拍板模块定位 |
| 面板配置（panel_config） | 面板自身设置单例：监听地址/端口、安全入口路径及开关、面板绑定域名、HTTPS 模式与证书、更新检查开关、界面语言等 | kb 对象表登记；存储形态（键值/结构化单例）留待 D2 领域建模 |
| 安全入口路径 | 可选的随机 URL 前缀门槛，未携带者被拒绝进入业务 | R-10 |
| 面板域名绑定（bind_domain） | panel_config 的可选 Host 级强校验项：绑定后仅该域名 Host 可达面板，IP 直连与其他 Host 一律标准 404（无业务错误码包裹） | ADR-028；与安全入口路径同为防探测门槛；读态失败 fail-closed |
| 面板证书 ACME 签发 | 面板自身证书经 ACME HTTP-01（挑战经已有 nginx 完成）签发与续期，证书来源在自签/导入之外扩展 ACME | ADR-029；复用 site-mgmt AcmeGateway 与 nginx 安全写回（跨模块消费契约）；不新增独立 80 端口监听；DNS-01 二期 |
| HTTPS 三态 | 面板自身 HTTPS 的关闭/自签证书/导入证书三种模式 | R-10「建议但不强制」 |
| 需重启生效项 | 保存后需重启面板服务才生效的配置项（监听地址/端口） | D1 判定，全集见应用架构附录C |
| 即时生效项 | 保存后立即生效、无需重启的配置项 | D1 判定 |
| 透传展示项 | 归属其他模块、仅在面板设置中只读展示的配置项（如会话有效期） | 维护业务归 account-auth（ADR-019） |
| 更新检查开关 | 默认关闭、可完全禁用的版本检查开关；开启后仅版本比对提示，不在线升级 | R-09；idea.md §4.2 非目标 |
| 安装脚本（install.sh） | 一键安装脚本：下载二进制 + 生成 systemd unit，每一行可读可审计 | ADR-009/D9 |
| CLI 管理通道 | 服务器终端经 `dougong` 子命令族对面板自身的本地管理通道：直接操作本机数据目录/SQLite、复用进程内业务能力，无 HTTP 绕行、无面板页面 | ADR-030；变更审计 source=cli（枚举池既有 audit_source）；裸 `dougong`=启动服务；密码重置账户业务归 account-auth（ADR-017 同族） |
| 单二进制（go:embed） | 前端资源内嵌的单一可执行文件交付形态，无运行时依赖 | D9/ADR-011 |
| 模块挂载点 | 业务模块页面接入外壳的子路由/菜单项登记 | 清单见应用架构附录D，随各模块 D1 联动 |
| 认证页面承载 | 外壳为登录页/初始化向导页提供的路由容器 | 认证业务归 account-auth（ADR-017） |
