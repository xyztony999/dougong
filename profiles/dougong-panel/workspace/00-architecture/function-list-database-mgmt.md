## 第一部分：文档概述

### 1.1 背景与目标

依据《斗拱面板 数据库管理（database-mgmt）应用架构》（application-arch-database-mgmt.md v1.0），按用户类型分章列出数据库管理可操作的菜单项与功能点描述，作为功能开发、页面设计（D4）与权限配置的依据。功能点遵循的业务规则：R-15 存量自动发现（发现即接管）、R-03 全变更审计、R-08 命令一律参数数组（mysqldump 等落点）、ADR-007 范围边界（MVP 仅 MySQL/MariaDB + Redis）、ADR-018 只读边界，及 D1 落定口径 ⚠️A18（凭据密文不回显）/⚠️A19（探测范围）/⚠️A20（实例移除纳管）。

### 1.2 文档定位

| 定位 | 说明 |
|------|------|
| 本文档做什么 | 按用户类型分章，列出每个用户可操作的菜单项和功能点描述，作为功能开发和权限配置的依据 |
| 本文档不做什么 | 不涉及技术实现方案、不涉及数据库设计、不涉及接口定义和系统架构 |

## 第二部分：功能清单

> 本章按用户类型分章，每章按应用域→功能模块→功能子模块逐层描述菜单和功能点。

### 本清单概览

数据库管理面向两类操作者（访客不涉及——全部功能位于登录会话之后）：

- **管理员（admin）**：覆盖本域全部功能——实例纳管治理（凭据/清单/移除）、MySQL 库与用户/授权/密码治理、双引擎观测、备份导出导入、Redis key 浏览；
- **只读用户（readonly）**：按 D0 口径与 ADR-018「全模块可查看」——可查看纳管实例清单、数据库列表、数据库用户列表、MySQL 状态概览/进程列表、Redis info 状态/慢日志；key 浏览属数据内容取出，不对只读角色开放（D0 readonly 查看清单未含）。

全局行为说明（无独立菜单，作用于全部章节）：存量实例探测（S-31-01）随模块进入自动执行、新实例自动进入纳管清单（R-15 发现即接管），重新探测经实例清单菜单由管理员触发；全部变更类操作自动记入审计（R-03，凭据值脱敏）；实例凭据任何界面与接口不回显（⚠️A18）。

## 2.1 管理员（admin）

**用户类型概述**：数据库管理域全部变更类操作与 key 浏览的执行者：纳管存量实例、治理库/用户/授权/密码、观测双引擎实况、执行库级备份导出导入；所有变更动作自动记入审计（R-03）。

#### 2.1.1 支撑业务域

**应用域概述**：管理员经纳管线接管存量实例，经 MySQL/MariaDB 与 Redis 两条治理线管理实例内对象与访问设置，经数据保护线执行库级备份。

## 2.2 只读用户（readonly）

**用户类型概述**：按 D0 口径与 ADR-018「全模块可查看 + 禁一切变更」：可查看纳管实例清单、数据库列表、数据库用户列表、MySQL 状态概览/进程列表、Redis info 状态/慢日志；无凭据配置、无任何治理变更、无备份导出导入、无 key 浏览（key 值属数据内容取出，D0 readonly 查看清单未含）；越界操作被拒绝并明确提示边界原因。

### 附录B：设计假设与解释性决策

| 编号 | 内容 | 说明 |
|------|------|------|
| ⚠️A18 | 实例凭据密文存储：密文落 SQLite、明文仅内存态建连、任何接口不回显、审计脱敏 | D0 待细化项业务口径落定（AA 附录B）；密钥来源与算法归 D2/D3 安全设计 |
| ⚠️A19 | 探测范围：socket 常见路径 + localhost:3306/6379，不做全网段扫描 | D0 建议口径采纳（AA 附录B） |
| ⚠️A20 | 实例移除纳管纳入范围：仅解除管理关系，不卸载/不停止/不删数据 | 材料未列，按纳管生命周期终局补全；如裁剪需同步三文档（BA/AA 同源标注） |
| 解释 | 只读角色可看 MySQL 进程列表与数据库用户列表 | D0 枚举未列；按 ADR-018 全可看口径与慢日志同敏感级开放；凭据任何角色不回显 |
| 解释 | 只读角色不可 key 浏览 | key 值属数据内容取出（D0 readonly 查看清单未含），从紧把握 |
| 解释 | 只读角色不可备份导出 | 导出属数据取出（与 account-auth 审计导出同判），且 ADR-018 禁上传下载 |
| 解释 | root 密码修改 / Redis 密码设置成功后面板侧凭据自动同步 | 维持既有纳管关系不失效，避免改密后实例失管 |
