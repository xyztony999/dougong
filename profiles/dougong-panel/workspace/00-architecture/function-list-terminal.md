## 第一部分：文档概述

### 1.1 背景与目标

依据《斗拱面板 Web 终端（terminal）应用架构》（application-arch-terminal.md v1.0），按用户类型分章列出 Web 终端可操作的菜单项与功能点描述，作为功能开发、页面设计（D4）与权限配置的依据。功能点遵循的业务规则：R-18 面板会话鉴权复用与运行身份、R-02 同源 Cookie 会话、ADR-018 只读角色禁 Web 终端、ADR-023 终端限流标准档（每用户并发 5 / 空闲 30 分钟断开 / 单连接硬上限 8 小时）。

## 第二部分：功能清单

> 本章按用户类型分章，每章按应用域→功能模块→功能子模块逐层描述菜单和功能点。

### 本清单概览

Web 终端面向两类操作者，能力分布极端不对称：

- **管理员（admin）**：Web 终端的唯一使用者——新建终端会话（默认身份或指定系统用户）、浏览器内双向交互、主动断开会话；
- **只读用户（readonly）**：按 ADR-018「禁 Web 终端」被整体拒绝——本域对其无任何菜单与功能，越界连接握手在鉴权处被拒绝并明确提示边界原因。

全局行为说明（无独立菜单，作用于管理员全部会话）：WS 握手鉴权与角色判定（S-38-01）随每次连接建立自动执行（无有效面板会话或只读角色即拒绝，R-18/ADR-018）；并发准入控制（S-38-02）随连接建立判定配额（每用户 5，超限拒绝提示先关闭既有会话，ADR-023）；会话生命周期管控（C-11-01~03）为会话存续期自动机制——空闲 30 分钟无输入断开（输出不重置计时）、单连接满 8 小时强制断开、面板会话过期/登出/强制下线联动断开全部该操作者终端（ADR-023/R-18）；断连清理与资源释放（S-41-02）在任一断开路径后统一回收 shell 进程、销毁内存态会话记录并释放并发配额。以上机制型子模块与菜单的映射见 AA 附录A。

## 2.1 管理员（admin）

**用户类型概述**：Web 终端的唯一使用者：以默认身份（面板运行用户，通常 root）或指定系统用户身份新建终端会话，在浏览器内与服务器 shell 双向交互（vim/top 等全屏程序正常渲染，里程碑 M5 验收口径），并可主动断开会话。会话全程受并发 5/空闲 30 分钟/硬上限 8 小时限流约束（ADR-023）。

#### 2.1.1 支撑业务域

**应用域概述**：管理员的终端操作动线：新建会话（运行身份选择）→ 浏览器交互（终端交互通道）→ 主动断开（会话断开与资源释放）。核心业务域（会话生命周期管控 C-11）为自动机制，无独立菜单（经全局行为覆盖）。

##### 2.1.1.1 运行身份选择（S-39）

**功能说明**：新建终端会话时的运行身份确定：默认面板运行用户，或指定一个系统用户（R-18）。

###### 默认身份接入（S-39-01）

**功能说明**：以面板运行用户（通常 root）身份新建终端会话。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 新建终端会话（默认身份） | 以面板运行用户（通常 root）身份新建一条终端会话并进入交互；建立时自动执行握手鉴权（S-38-01）与并发准入（S-38-02）——并发达上限 5 时拒绝并提示先关闭既有会话（ADR-023） | 默认身份接入（S-39-01） | 鉴权与并发判定为机制型（AA 附录A） |

###### 指定系统用户接入（S-39-02）

**功能说明**：从系统用户清单选择身份新建终端会话。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 新建终端会话（指定系统用户） | 从系统用户清单（system_user）选择一个具备登录 shell 的用户身份新建终端会话：以面板运行用户权限代为启动所选用户的登录 shell（su 语义），不做密码代输；并发约束同默认身份 | 指定系统用户接入（S-39-02） | 指定范围与切换语义为 D1 落定口径（附录B） |

##### 2.1.1.2 终端交互通道（S-40）

**功能说明**：终端会话建立后的浏览器双向交互。

###### 终端输出呈现（S-40-01）

**功能说明**：浏览器终端页：服务器 shell 输出实时回传呈现。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| Web 终端 | 浏览器终端页交互：服务器输出实时呈现；操作者键入（命令、控制键）实时下发执行；窗口尺寸变化同步，全屏程序（vim/top）正常渲染；多标签承载多会话，标签数上限 = 并发阈值 5（D0 建议形态，页面细节归 D4） | 终端输出呈现（S-40-01） | 输入传递（S-40-02）经本菜单项功能点覆盖（AA 附录A）；每次输入兼作空闲判定的活跃信号 |

##### 2.1.1.3 会话断开与资源释放（S-41）

**功能说明**：终端会话的主动终结入口（统一清理为机制型）。

###### 用户主动断开（S-41-01）

**功能说明**：操作者主动断开终端会话。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 会话断开 | 关闭终端标签页或会话：立即断开连接，服务器侧 shell 进程随之终止，并发配额即时释放 | 用户主动断开（S-41-01） | 统一清理与配额释放由 S-41-02 承载（机制型，AA 附录A） |

## 2.2 只读用户（readonly）

**用户类型概述**：按 ADR-018「禁 Web 终端」：本域对只读用户无任何菜单与功能——界面不提供终端入口，越界发起的终端连接握手在鉴权与角色判定处被拒绝并明确提示边界原因。本章节用于显式登记该角色边界，作为权限配置依据；无应用域章节（无可操作功能子模块）。

## 3.1 管理员（admin）功能视图

```
管理员（admin）
└── 支撑业务域
    ├── 运行身份选择（S-39）
    │   ├── 默认身份接入（S-39-01）
    │   │   └── 新建终端会话（默认身份） — 以面板运行用户（通常 root）新建
    │   └── 指定系统用户接入（S-39-02）
    │       └── 新建终端会话（指定系统用户） — 选择登录 shell 用户，su 语义不代输密码
    ├── 终端交互通道（S-40）
    │   └── 终端输出呈现（S-40-01）
    │       └── Web 终端 — 输出实时呈现 + 键入下发 + 尺寸同步（输入传递经本菜单覆盖）
    └── 会话断开与资源释放（S-41）
        └── 用户主动断开（S-41-01）
            └── 会话断开 — 关闭标签/会话立即终结并释放配额
```
