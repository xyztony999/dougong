> 引擎 design 阶段 D0 产物（2026-11-12，批量澄清）。作为 D1 架构设计的直接输入。
> 需求来源：idea.md §4.1 M1（骨架部分）/§5.4（面板自身安全）/§2 D9 + knowledge/business-concepts（panel_config、R-09/R-10、ADR-009/011/012）。

## 1. 业务概念解析

| 维度 | 内容 |
|------|------|
| 业务术语 | 面板外壳（布局/导航/菜单）、面板配置、安全入口路径、HTTPS、更新检查开关、安装脚本、go:embed、版本信息 |
| 业务流程 | install.sh 安装（下载二进制 + systemd unit）→ 服务启动 → 首次访问（未初始化→初始化向导〔account-auth〕）→ 登录 → 面板外壳挂载各模块页面 |
| 业务角色 | 管理员 admin、只读 readonly（菜单/页面可见性按 RBAC，ADR-018） |
| 业务规则 | R-09 更新检查默认关闭且可完全禁用、零外呼；R-10 默认监听 `0.0.0.0:随机高位端口`、可选安全入口路径、建议但强制 HTTPS；ADR-009 安装脚本每一行可读 |
| 业务数据 | panel_config（监听地址/端口、安全入口、HTTPS、更新检查开关） |

## 2. 架构匹配与类型判定

- 匹配结果：panel_config 对象已在 kb 登记；初始化/登录已由 account-auth 模块设计（跨模块依赖，非重复设计）；workspace 无 panel-core 专属设计文档 → **无匹配，新增**

## 5. D1 输入摘要（结构化需求）

**模块边界**：
- IN：前端应用骨架（Vue3+Vite+Pinia+Naive UI、路由、布局、菜单与 RBAC 可见性）、panel_config 读写与生效流程、监听地址/端口与安全入口路径、HTTPS 配置（自签/导入证书/关闭三态）、更新检查开关（默认关）、安装脚本 install.sh + systemd unit、版本信息展示
- OUT：登录/会话/RBAC/审计（account-auth）、监控仪表盘数据与图表（monitoring 提供数据，本模块只提供页面框架）、各业务功能页面（各模块自带）、面板在线自升级（非目标，§4.2 仅版本检查开关）

**核心实体**：panel_config（单行键值或结构化单例：监听地址/端口、安全入口路径及开关、HTTPS 模式与证书、更新检查开关、语言等）

**状态机**：无（配置为单例资源，变更即生效/提示重启项）
