## 第一部分：文档概述

### 1.1 背景与目标

将《斗拱面板 面板基座（panel-core）业务架构》（business-arch-panel-core.md v1.1）的 7 个 L3 关键业务按 DDD 四层归类为应用域，组织为功能模块/功能子模块，标注涉及用户类型与模块间调用关系，作为 PRD（D2）、API 设计（D3）与交互设计（D4）的功能组织依据。

DDD 归类结论（依据 d1 分册归类原则逐条判定）：

- **支撑业务域**：全部 7 个 L3 归入此层——安装与部署（含 ADR-009「脚本每行可读」与本域 CLI 本地直读数据目录（ADR-030）的信任规则）、监听与入口接入（含 R-10 最小暴露与入口门槛规则、ADR-028 域名绑定 Host 强校验规则）、HTTPS 接入治理（含 R-10「建议但不强制」口径规则、ADR-029 面板证书 ACME 经 nginx 规则）、应用骨架与导航（菜单可见性消费 ADR-018 角色边界规则）、模块页面挂载（模块统一接入的组织规则）、面板配置管理（panel_config 聚合根与「即时生效/需重启」生效规则）、版本与更新检查治理（R-09 零外呼默认关规则）——七者均含本域特有业务规则，但均无生命周期状态机（D0：配置为单例资源，变更即生效/提示重启项），故不入核心业务域；
- **核心业务域**：无——本模块无任何生命周期状态机与单据驱动主链（HTTPS 三态为模式枚举、入口/更新检查为开关，均非状态机；v1.1 增量判定：面板证书 ACME 签发/续期为单例证书对象 panel_cert（单行 id=1）上的动作与来源扩展（ADR-029），非多实例证书生命周期状态机——与 site-mgmt 多实例 certificate 聚合根（C 域）的本质差异，归类不变）；面板基座本质为基础设施模块，其价值在为全模块提供运行载体与入口治理；
- **基础数据域**：无——panel_config 为行为型配置（承载生效流程与入口拦截决策），非「仅作下拉/分类标签」的系统级引用数据，不满足基础数据域「不承载业务决策逻辑」判据；
- **平台支撑域**：无——安装脚本（ADR-009 信任规则）、入口治理（R-10）、更新检查（R-09）均含本领域特有业务规则，不满足「零业务语义、换行业可原样复用」判据。

> 模块编码衔接说明（编码规则的跨模块执行口径）：功能模块编码全局唯一，承接 account-auth 已占用的 C-01~C-03、S-01~S-05，本模块全部功能模块属支撑业务域，自 S-06 起编至 S-12（依据「新模块在域内最大序号后递增」）。

## 第二部分：应用架构

> 本章按应用域逐层描述功能模块与功能子模块。每个应用域有其概述，每个功能模块/子模块有功能说明及涉及用户类型。

### 本架构概览

应用架构按 DDD 四层聚为唯一应用域——**支撑业务域**，其下按「运行载体 → 入口面 → 呈现面 → 治理面」组织 7 个功能模块：

- **运行载体**：安装与部署（S-06）交付可常驻运行的面板服务，并承载运行期 CLI 管理通道（S-06-04，ADR-030）；
- **入口面**：监听与入口接入（S-07）与 HTTPS 接入治理（S-08）构成入站访问的四道门槛（绑定面/URL 门槛/Host 强校验/传输层）；
- **呈现面**：应用骨架与导航（S-09）与模块页面挂载（S-10）构成全模块统一外壳；
- **治理面**：面板配置管理（S-11）与版本与更新检查治理（S-12）构成运行期自身治理。

调用关系总脉络：配置项统一存取经面板配置管理（S-11-01）落 panel_config；入口治理（S-07/S-08）读取配置作拦截/协商判定；外壳（S-09）按模块挂载点清单（S-10-01）组织路由与菜单，菜单可见性消费 account-auth 角色判定（ADR-018）；认证页面（S-10-02）调用 account-auth 初始化与登录业务；全部配置变更经 account-auth 审计契约留痕（R-03）；会话参数透传展示（S-11-03）只读读取 account-auth 会话策略（ADR-019）；面板证书 ACME 签发与续期（S-08-03）跨模块消费 site-mgmt 的 AcmeGateway 签发通道与 nginx 安全写回（ADR-029，本模块首个跨模块 OHS 消费契约）；CLI 管理通道（S-06-04）于服务器终端直读数据目录/SQLite，复用进程内配置业务（S-11-01）与 account-auth 账户/审计业务（ADR-030）。跨模块契约与模块边界详见附录B。

全部 L3 的 L4 组织模式判定（d1 分册 Step 1 自动判定）：均为 **standard 模式**——各 L4 相互独立可分别操作，无「开始→结束」时序引导流程，L4 一一映射为功能子模块。

### 应用域分层

> 按 DDD 战略设计，将应用域归入不同分层，决定后续详细设计的建模深度和投入策略。AA 应用域严格按照 DDD 四层划分，每个 BA L3 按 L3→DDD 四层归类原则归入对应分层。

| 分层 | 说明 | 包含功能模块 |
|------|------|-------------|
| 核心业务域 | 承载核心业务价值，有状态机和聚合根，深度建模 | —（本模块无：无生命周期状态机与单据主链，D0 拍板配置为单例资源无状态机；归类推导见 1.1） |
| 支撑业务域 | 为核心业务提供必要的业务支撑能力，包含业务规则，独立上下文 | 安装与部署（S-06）、监听与入口接入（S-07）、HTTPS 接入治理（S-08）、应用骨架与导航（S-09）、模块页面挂载（S-10）、面板配置管理（S-11）、版本与更新检查治理（S-12） |
| 基础数据域 | 系统级引用数据，无业务状态机，薄适配 | —（无：panel_config 为行为型配置，承载生效与拦截决策，非下拉/分类类引用数据） |
| 平台支撑域 | 纯技术能力，零业务语义，可复用 | —（无：安装/入口/更新检查均含本域特有业务规则 ADR-009/R-10/R-09） |

### 2.1 支撑业务域

**应用域概述**：面板基座全部功能能力所在层：为全部业务模块提供交付载体（安装部署）、入站门槛（监听/入口/HTTPS）、统一外壳（骨架/挂载）与自身治理（配置/版本）。服务的用户群体：管理员（admin）维护全部配置，只读用户（readonly）查看设置项当前值，访客（未认证操作者）触达入口拦截、HTTPS 提示与认证页面容器，并在服务器终端执行安装脚本与 CLI 管理通道（S-06-01/S-06-04，ADR-030）。

#### 2.1.1 安装与部署（S-06）

**功能说明**：面板交付与常驻运行能力：可审计一键安装脚本、systemd 服务托管、单二进制内嵌产物与运行期 CLI 管理通道（ADR-009/D9/ADR-030）。本模块为服务器侧能力，无面板内页面。

**涉及用户类型**：- [ ] 管理员（admin） - [ ] 只读用户（readonly） - [✓] 访客（未认证操作者）（安装执行者，执行时面板尚无账户体系）

**功能说明**：install.sh 一键安装：下载二进制、落位文件、生成并启用 systemd unit；脚本每一行可读可审计（ADR-009）。

**涉及用户类型**：- [ ] 管理员（admin） - [ ] 只读用户（readonly） - [✓] 访客（未认证操作者）（服务器终端执行，非面板页面功能）

##### 2.1.1.4 CLI 管理通道（S-06-04）

**功能说明**：服务器终端经 `dougong` 子命令族对面板自身的本地管理通道（宝塔同款定位，ADR-030）：直接操作本机数据目录/SQLite、复用进程内 service 层（单二进制优势，无 HTTP 绕行）。子命令族：状态查询（systemd 状态+初始化态+访问 URL）、运行信息（版本/端口/入口路径/HTTPS/数据目录）、管理员密码重置（-username + 环境变量注入新密码，同初始化口径）、端口设置、安全入口路径查看/重生成/关闭、面板服务启停/重启/状态（systemctl 参数数组，R-08）。读命令在服务运行时可直读；写命令完成后提示 `systemctl restart dougong` 生效；变更动作写审计（source=cli，枚举池既有 audit_source，R-03）；裸 `dougong` 仍为启动服务。无面板页面。

**涉及用户类型**：- [ ] 管理员（admin） - [ ] 只读用户（readonly） - [✓] 访客（未认证操作者）（服务器终端操作者，本地通道无面板会话；CLI 变更动作的权限来自终端系统权限而非面板角色）

##### 2.1.3.3 面板证书 ACME 签发与续期（S-08-03）

**功能说明**：面板自身证书的 ACME 签发与续期编排：HTTP-01 挑战经服务器已有 nginx 完成（不新增独立 80 端口监听），挑战 location 的临时注入与撤除走 nginx 安全写回流程（备份→临时注入 /.well-known/acme-challenge location→签发→撤除→`nginx -t`→失败回滚保障），签发/续期经 ACME 签发网关（AcmeGateway）——两者均复用 site-mgmt 既有能力（ADR-029 跨模块消费契约，本模块不自建 ACME 通道）；证书产物落面板证书 panel_cert（证书来源在自签/导入之外扩展 acme），HTTPS 模式随之联动（S-08-01）；到期前自动续期，失败可手动重试；DNS-01 通配符证书为二期事项。

**涉及用户类型**：- [✓] 管理员（admin） - [✓] 只读用户（readonly）（可查看证书状态与概要） - [ ] 访客（未认证操作者）

**调用关系**：

| 调用模块/子模块 | 调用说明 |
|---------------|---------|
| ACME 签发通道（site-mgmt AcmeGateway） | 面板证书签发/续期经其 ACME 协议交互（lego ACL，R-09 除外条款通道；ADR-029 跨模块 OHS 消费） |
