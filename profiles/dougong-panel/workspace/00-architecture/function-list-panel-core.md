## 第一部分：文档概述

### 1.1 背景与目标

依据《斗拱面板 面板基座（panel-core）应用架构》（application-arch-panel-core.md v1.1），按用户类型分章列出面板基座可操作的菜单项与功能点描述，作为功能开发、页面设计（D4）与权限配置的依据。功能点遵循的业务规则：R-09 零遥测（更新检查默认关且可完全禁用）、R-10 监听/入口/HTTPS 入口面（默认 0.0.0.0:随机高位端口、可选安全入口路径、建议但强制 HTTPS）、R-03 全变更审计、ADR-009 可审计安装脚本、ADR-018 只读边界（全可看 + 禁一切变更）、ADR-019 会话有效期策略（透传展示）、ADR-028 面板域名绑定强校验（绑定后 IP/其他 Host 标准 404）、ADR-029 面板自身证书 ACME 经已有 nginx（复用 site-mgmt AcmeGateway 与 nginx 安全写回）。

### 1.2 文档定位

| 定位 | 说明 |

| 本文档不做什么 | 不涉及技术实现方案、不涉及数据库设计、不涉及接口定义和系统架构 |

## 第二部分：功能清单

> 本章按用户类型分章，每章按应用域→功能模块→功能子模块逐层描述菜单和功能点。

### 本清单概览

面板基座面向两类面板用户：

- **管理员（admin）**：面板自身设置的唯一变更者——监听/入口/HTTPS/参数/更新检查配置维护，版本与会话参数查看；
- **只读用户（readonly）**：按 ADR-018「全可看 + 禁一切变更」——可查看面板设置项当前值，无任何变更与触发入口。

无访客章说明：访客（未认证操作者）触达的面板基座能力均为机制或容器——安装脚本（S-06，服务器终端执行）、安全入口拦截网关（S-07-02）、首访 HTTPS 提示（S-08-02）、登录/初始化页面容器（S-10-02，其菜单归 account-auth 功能清单）——均不构成本模块的独立面板菜单（见附录B）。

全局行为说明（无独立菜单，作用于全部章节）：布局与路由骨架、菜单按角色过滤渲染为全局界面机制；安全入口拦截网关作用于全部入站访问；HTTPS 终结于传输层；配置变更审计经 account-auth 契约随变更动作自动发生（R-03）；安装部署（S-06）经服务器终端执行，无面板菜单。

## 2.1 管理员（admin）

**用户类型概述**：面板自身设置的唯一变更者：维护监听地址/端口、安全入口路径、面板绑定域名、HTTPS 三态与面板证书 ACME 申请/手动重试续期、界面语言与更新检查开关（全部变更记审计，R-03），查看版本信息与会话参数透传展示。安装部署（S-06）经服务器终端执行，无面板菜单（附录B）。

#### 2.1.1 支撑业务域

**应用域概述**：面板基座全部功能模块均归支撑业务域，为全模块提供入口面、呈现面与治理面支撑。

### 附录B：设计假设与解释性决策

| 编号 | 内容 | 说明 |
|------|------|------|
| 决策 | 生效方式判定：仅监听地址/端口需重启生效，其余（安全入口/HTTPS/更新检查/语言）即时生效 | D0 待细化项的 D1 判定；全集见 AA 附录C，如 D3 实现发现例外需回写 |
| 决策 | 功能模块编码承接 account-auth 全局序：本模块支撑业务域编 S-06~S-12 | 依据编码规则「新模块在域内最大序号后递增」，保证聚合视图与 API 文件夹编码全局唯一 |
| 解释 | 只读用户可查看安全入口路径值与全部设置项 | ADR-018「全模块可查看」直接适用；如需收紧安全入口可见性属 ADR-018 修订事项，不在本模块内变更 |
| 解释 | 只读用户无更新检查「手动触发」入口 | 手动触发产生外部请求动作，从变更边界从紧把握（ADR-018 禁变更精神的延伸） |
| 解释 | 本模块无访客章 | 访客触达项均为机制（安装脚本/入口拦截/HTTPS 提示）或 account-auth 承载页（登录/初始化菜单归其功能清单），无独立面板菜单 |
| 解释 | 安装部署（S-06）不出现在面板菜单 | 安装发生在面板可用之前，经服务器终端执行（ADR-009），面板内无对应页面 |
| 边界 | panel_config 存储形态（单行键值/结构化单例）留待 D2 领域建模 | D0 遗留开放项，属领域建模决策，不阻断 D1 |
