## 第一部分：文档概述

### 1.1 背景与目标

依据《斗拱面板 网站管理（site-mgmt）应用架构》（application-arch-site-mgmt.md v1.0），按用户类型分章列出网站管理可操作的菜单项与功能点描述，作为功能开发、页面设计（D4）与权限配置的依据。功能点遵循的业务规则：R-06 安全写入四步、R-07 Raw 保留写回、R-15 存量自动发现、R-16 站点隔离写回、ADR-024 证书状态机，以及 D1 落定口径 ⚠️A13~A17（多配置目录写回落点 / PHP-FPM pool 对接 / 日志路径发现 / 证书托管 / 源码编辑对象边界）。

## 第二部分：功能清单

> 本章按用户类型分章，每章按应用域→功能模块→功能子模块逐层描述菜单和功能点。

### 本清单概览

网站管理面向两类操作者（无访客触达点，全部功能位于登录会话之后）：

- **管理员（admin）**：覆盖本域全部功能——存量导入结果消费、三模板建站、双模式站点编辑、站点启停/日志/重载、证书全生命周期治理；全部写回动作统一受安全写入治理约束（R-06：备份 → nginx -t → 失败自动回滚 + diff；R-16：其余站点零影响）；
- **只读用户（readonly）**：按 D0 口径与 ADR-018「全模块可查看 + 禁一切变更」——可查看站点列表/详情、证书清单、访问/错误日志尾部；无任何编辑、建站、启停、证书操作与删除能力。

全局行为说明（无独立菜单，作用于全部章节）：存量导入管线（扫描 → 指令树解析 → server 块提取 → 来源文件映射登记，S-26 全部）为系统自动机制，站点随扫描自动进出站点列表；安全写入治理（写前 conf.backup/时间戳/ 快照 → 写入 → nginx -t 校验 → 失败自动恢复并报错 diff → 站点隔离写回，S-30 全部）为全部写回动作的强制前置；Raw 未识别指令保留写回（S-28-05）随全部结构化编辑保存自动发生；证书自动续期调度（C-09-01）为后台任务，expiring_soon 自动触发、结果写审计；存量证书识别导入（C-10-01）随站点导入自动发生；校验通过后的生效统一经 nginx reload 通道。

## 2.1 管理员（admin）

**用户类型概述**：全部站点与证书变更类操作的执行者：三模板建站、双模式编辑、启停/重载、证书申请/部署/续期重试/删除；全部变更动作自动记入审计（R-03）。存量导入管线、安全写入治理、Raw 保留写回与自动续期调度为其不可见的全局行为。

## 2.2 只读用户（readonly）

### 附录B：设计假设与解释性决策

| 编号 | 内容 | 说明 |
|------|------|------|
| ⚠️A13 | 「站点 → 来源文件」映射消重、写回原文件 | conf.d 与 sites-enabled 并存去重口径（D0 建议采纳）；如裁剪需同步 BA/AA/FL 三文档 |
| ⚠️A14 | 发现已有 PHP-FPM pool 列出供选择，FastCGI 参数模板内置 | 不新装 PHP（D0 建议采纳） |
| ⚠️A15 | 日志路径 = access_log/error_log 指令解析 + 默认路径回退 | D0 建议采纳 |
| ⚠️A16 | ACME 证书面板托管、续期原路径替换；存量证书保留源站原路径 | 具体存储路径常量归 D2/D3（建议值 /etc/dougong/certs/） |
| ⚠️A17 | Monaco 源码编辑对象限定站点配置文件，不开放全局主配置编辑 | 沿「站点对象」语义推导；如需开放需同步三文档 |
| 解释 | 停用站点（disabled）不等于删除 | 启停仅切换 enabled 状态，保留配置与证书引用；删除站点不在 MVP 范围（idea.md §4.1 M4 站点级操作仅启停） |
| 解释 | 证书删除的引用提示与存量证书删除语义 | 有站点引用时提示先解除部署（防误删致 TLS 失效）；存量证书删除仅解除管理关系、不删源站文件 |
| 解释 | ADR-024 文本称「6 状态机」而枚举命名 5 个状态（pending/valid/expiring_soon/expired/renew_failed） | 本清单按枚举命名与流转执行；「第 6 状态」语义待 ADR-024 侧澄清，如为申请中等中间态需修订 ADR-024 并同步三文档与枚举池 |
| 解释 | 存量导入、安全写入、Raw 保留写回、自动续期、存量证书识别导入无独立菜单 | 机制型能力（AA 附录A 映射），其业务行为经宿主菜单功能点描述与全局行为说明覆盖 |
