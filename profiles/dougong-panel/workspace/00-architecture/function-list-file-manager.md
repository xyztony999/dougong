## 第一部分：文档概述

### 1.1 背景与目标

依据《斗拱面板 文件管理器（file-manager）应用架构》（application-arch-file-manager.md v1.0），按用户类型分章列出文件管理器可操作的菜单项与功能点描述，作为功能开发、页面设计（D4）与权限配置的依据。功能点遵循的业务规则：R-04 路径白名单（EvalSymlinks + 前缀校验防逃逸）、R-05 上传临时文件+rename/分块、R-17 删除进回收站（ADR-021）、R-03 全变更审计、ADR-018 只读边界（禁变更、禁上传下载）、⚠️A12 受管根与排除目录配置入口纳入范围。

## 第二部分：功能清单

> 本章按用户类型分章，每章按应用域→功能模块→功能子模块逐层描述菜单和功能点。

### 本清单概览

文件管理器面向两类操作者：

- **管理员（admin）**：受管根内全部文件能力的执行者——浏览导航、上传下载、在线编辑、整理、权限属主、压缩解压与回收站治理（还原/清空/白名单配置）；所有变更动作自动记入审计（R-03）；
- **只读用户（readonly）**：按 ADR-018「全模块可查看 + 禁一切变更 + 禁上传下载」——同等查看目录内容、导航与回收站列表；上传/下载/编辑/整理/权限属主/压缩解压/还原/清空全部无入口，越界请求被全局边界管控拒绝（account-auth S-03-02）。

全局行为说明（无独立菜单，作用于全部章节）：路径白名单校验（S-19-01）为全部文件操作请求的强制前置——所有路径先解析真实路径再校验白名单，越界操作一律拒绝并明确提示越界原因（R-04，无独立页面）；回收站入站登记（C-06-01）为「删除」菜单的操作后半程——条目移入 `.dougong-trash/` 唯一标识子目录并写 trash_entry 落库（R-17，宿主菜单覆盖，映射见 AA 附录A）。

## 2.1 管理员（admin）

**用户类型概述**：受管根内全部文件能力的执行者。所有写类操作的目标路径均经路径白名单校验（R-04）前置把关；上传/移动/解压/还原的同名冲突均为显式决策（覆盖或跳过/放弃），不做静默覆盖；所有变更动作记审计（R-03），下载按数据取出口径记审计。

#### 2.1.1 核心业务域

**应用域概述**：管理员治理删除缓冲闭环：回收站列表查看、还原与清空。

##### 2.1.1.1 回收站治理（C-06）

**功能说明**：trash_entry（落 SQLite）的缓冲治理；状态机「在站 → 已还原 / 已清空」（kb 拍板）。

###### 回收站列表查看（C-06-02）

**功能说明**：在站条目清单查看。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 回收站列表 | 查看全部在站条目：原路径、删除时间、操作者、类型（文件/目录）、大小；已还原/已清空终态记录不出现 | 回收站列表查看（C-06-02） | |

###### 回收站还原（C-06-03）

**功能说明**：在站条目移回原路径。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 回收站还原 | 将在站条目移回 trash_entry 记录的原路径；原路径被占用时提示显式选择覆盖或放弃（不自动改名）；成功后条目转已还原终态 | 回收站还原（C-06-03） | 变更类操作，记审计 |

###### 回收站清空（C-06-04）

**功能说明**：在站条目的终局销毁。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|

## 2.2 只读用户（readonly）

**用户类型概述**：按 ADR-018「全模块可查看 + 禁一切变更 + 禁上传下载」：同等查看目录内容、导航与回收站列表；全部内容操作（含下载）与还原/清空/白名单配置对本角色无入口，越界请求被全局边界管控拒绝并明确提示边界原因。

#### 2.2.1 核心业务域

**应用域概述**：只读用户的回收站可观测（无还原/清空入口）。

**功能说明**：在站条目清单查看（无治理动作）。

#### 2.2.2 支撑业务域

### 附录B：设计假设与解释性决策

| 编号 | 内容 | 说明 |
|------|------|------|
| ⚠️A12 | 受管根与排除目录配置入口纳入本模块范围 | 推导自 R-04「默认 /，可配置排除 /proc、/sys 等」语义；D0 输入清单未显式列出；如裁剪需同步 BA/AA/FL 三文档 |
| 解释 | 同名冲突一律显式决策（上传/移动/解压=覆盖或跳过，还原=覆盖或放弃），不做静默覆盖与自动改名 | 覆盖/被覆盖均为不可逆动作，操作者必须知情确认；BA 2.3.1.3 还原冲突为 D0 待细化项落定 |
| 解释 | 下载动作记审计 | 下载为数据取出，从紧把握——与账户与安全基座「审计导出记审计」同口径；ADR-018 对只读角色禁下载 |
| 解释 | 目录浏览默认全量呈现（含点开头隐藏条目），不设隐藏开关 | 运维场景需直视 `.env`、`.htaccess` 等配置文件 |
| 解释 | 在线编辑拒绝二进制与超大文件（上限数值归 D2/D3） | 全量加载编辑的内存安全边界；D0 未列数值 |
| 边界 | 磁盘配额、编辑器版本历史/协同、目录打包下载、断点续传、回收站自动清理不在功能清单 | D0 边界 OUT / 二期（BA 1.4） |
