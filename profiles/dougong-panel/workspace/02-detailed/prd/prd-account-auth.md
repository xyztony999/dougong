## 第一部分：业务目标（G1）

为斗拱面板提供账户与安全基座：让自托管运维者通过**初始化双入口**安全取得面板控制权（ADR-017），以**密码 + 可选 TOTP**登录（R-01 锁定防暴力破解），在 **HttpOnly Cookie 会话 + CSRF** 保护下操作面板（R-02），凭 **admin/readonly 两角色**获得差异化权限（ADR-018），并使**全部变更类操作可审计、可追溯、按 90 天保留自动治理**（R-03、ADR-020）。服务对象：单机自托管的个人运维者（管理员）及其协作者（只读观察者）。

本域是横切基座：审计接口被全部业务模块调用（R-03），会话鉴权被 Web 终端等 WS 场景复用（R-18），RBAC 是全站权限基线。「可信」（零遥测 + 全变更可审计）是产品三大支柱之一（idea.md §1/§3，对比宝塔遥测事件 §9.3），本域是该支柱的直接承载者。

## 第二部分：功能范围（G2）

**IN（做什么）**：

| # | 能力 | 依据 |
|---|------|------|
| 1 | 初始化引导：Web 首访向导 + CLI 子命令，双入口互斥（先落库者胜出仲裁），未初始化全站拦截 | ADR-017 |
| 2 | 登录认证：密码 + 可选 TOTP（RFC 6238，30 秒窗口 ±1）；连续 5 次失败锁 15 分钟、期满自动解除 | R-01、D0 §5 |
| 3 | 会话管理：签发（HttpOnly Cookie + CSRF）、绝对过期 12h + 空闲滑动续期 2h（均可配置）、登出、在线会话查看、管理员强制下线 | ADR-019、R-02 |
| 4 | 账户管理：管理员创建/删除用户、角色指派、密码重置；全员自助改密与 TOTP 绑定解绑 | A11（多用户+RBAC 前提，idea.md §4.1 M1:60） |
| 5 | 访问控制：逐请求鉴权、只读边界（全可看含审计 + 禁变更/终端/上传下载）、WS 鉴权复用 | ADR-018、R-18、R-02 |
| 6 | 审计：变更操作与安全事件只追加记录、条件查询、管理员导出、90 天每日自动清理（清理本身记审计） | R-03、ADR-020 |

**OUT（不做什么）**：

| # | 事项 | 归属 |
|---|------|------|
| 1 | 各业务模块内部的审计埋点实现（本域只定接口约定） | 各业务模块 |
| 2 | 面板自身 HTTPS/监听地址/安全入口路径 | panel-core（R-10 入口面） |
| 3 | Web 终端连接超时与并发限流 | terminal |
| 4 | 角色 CRUD（role 为固定枚举 admin/readonly） | MVP 不做 |
| 5 | 面板配置管理页（监听/端口/更新检查等） | panel-core（panel_config 对象） |
| 6 | 任何外部系统对接、外呼通知 | 无（R-09 零遥测零回传） |

## 第三部分：角色定义（G3）

| 角色 | 英文 | 职责与权限 | 获得方式 |
|------|------|-----------|---------|
| 管理员 | admin | 全部变更类操作 + 用户/会话/审计管理与导出 | 初始化创建首个；此后由其他管理员创建 |
| 只读用户 | readonly | 全模块可查看（含审计日志）；禁一切变更、禁 Web 终端、禁上传下载（ADR-018） | 管理员创建并指派 |
| 访客（未认证操作者） | — | 仅触达初始化向导（Web/CLI）与登录页；未初始化前被全站拦截引导 | — |

CLI 子命令操作者即「访客」的终端形态（服务器 SSH 运维人员），权限边界同向导：仅在未初始化时可执行。

## 第四部分：功能需求明细

### 4.1 初始化引导（C-01）

| 编号 | 需求 | 主流程与规则 | 审计 |
|------|------|-------------|------|
| FR-01 | Web 首次访问向导 | 未初始化态访问任意路由 → 重定向向导；输入用户名/密码（≥8 位，A10）/可选 TOTP 绑定 → 经**初始化仲裁**（单行标记先落库者胜出）创建首个 admin → 标记已初始化 → 向导永久关闭转登录页 | 初始化完成（安全事件） |
| FR-02 | CLI 子命令创建管理员 | `dougong` set-admin 类子命令，参数同向导；已初始化时拒绝并提示；并发与向导共用同一仲裁 | 初始化完成（安全事件） |
| FR-03 | 未初始化全站拦截 | 拦截一切业务路由（含 API）；初始化完成后自动失效（ADR-017） | — |

### 4.2 登录认证（C-02）

| 编号 | 需求 | 主流程与规则 | 审计 |
|------|------|-------------|------|
| FR-04 | 登录 | 用户名+密码（服务端校验，R-14）；TOTP 启用账户续验 6 位动态码（30s 窗口 ±1，动态码错误计一次失败）；成功 → 签发 HttpOnly Cookie 会话 + CSRF 令牌（token 不入 localStorage，R-02）；连续 5 次失败锁 15 分钟，锁定期间拒绝并提示剩余时间，期满自动解除（R-01）；第二因素顺序：TOTP 启用→动态码，否则有 passkey→passkey 断言（requiresPasskey + 一次性 login_ticket，AUTH_007 同构）；登录成功按设备指纹（dg_device cookie + UA 哈希）识别新设备并记审计 | 成功/失败/锁定/解锁（安全事件） |
| FR-22 | passkey 无密码登录 | 登录页「使用 passkey 登录」：用户名 + passkey 断言（WebAuthn）免密码签发会话；需域名 + HTTPS 安全上下文（IP 直连返回 AUTH_018）；失败计入 R-01 锁定计数 | 成功/失败（安全事件） |
| FR-23 | 恢复码登录 | 登录页「用恢复码登录」：用户名 + 一次性恢复码（passkey/TOTP 均不可用时的兜底）；每码仅可用一次，错误计入 R-01 锁定计数 | 成功/失败（安全事件） |


### 4.3 会话治理（C-03）

| 编号 | 需求 | 主流程与规则 | 审计 |
|------|------|-------------|------|
| FR-05 | 会话有效期管理（自动） | 绝对过期默认 12h（自建立起算）+ 空闲超时默认 2h（活跃滑动顺延），两项均可配置（ADR-019）；任一到期即失效 | — |

### 4.4 用户管理（S-01，⚠️A11）

| 编号 | 需求 | 主流程与规则 | 审计 |
|------|------|-------------|------|
| FR-09 | 用户创建与角色指派 | 创建 panel_user，指派 admin/readonly 二选一；密码 ≥8 位（A10） | 变更操作 |

### 4.5 账户自助管理（S-02，⚠️A11）

| 编号 | 需求 | 主流程与规则 | 审计 |
|------|------|-------------|------|
| FR-12 | 修改登录密码 | 验旧密码 → 设新密码（≥8 位）；成功后吊销本人其他会话、保留当前会话 | 安全事件 |
| FR-13 | TOTP 绑定与解绑 | 绑定：生成密钥二维码 → 验证一个动态码后生效；解绑：需密码确认；绑定状态决定下次登录是否索要动态码 | 安全事件 |
| FR-24 | passkey 管理 | 个人安全设置：注册本机 passkey（指纹/面部/安全密钥）、查看列表（名称/添加时间/最后使用）、删除本人 passkey；IP 直连或非安全上下文不可用并提示（AUTH_018）；私钥不出本机认证器，服务端只存公钥与标志位 | 注册/删除（安全事件） |
| FR-25 | 恢复码管理 | 个人安全设置：生成/重新生成 10 个一次性恢复码（重新生成作废旧码）；明文仅生成时展示一次，服务端只存哈希；剩余数量可查 | 生成（安全事件） |

## 第六部分：状态流转（T2）

| 对象 | 状态 | 流转 | 触发 |
|------|------|------|------|
| panel_user | 正常 | → 锁定 | 连续 5 次登录失败（R-01） |
| panel_user | 锁定 | → 正常 | 锁定期满（15 分钟）自动解除 |
| session | 有效 active | → 过期 expired | 绝对 12h 到期 或 空闲 2h 到期（ADR-019） |
| session | 有效 active | → 吊销 revoked | 登出 / 管理员强制下线 / 所属用户被删除或密码重置 / 本人改密（其他会话） |
| session | 过期 expired / 吊销 revoked | — （终态，记录可清理） | — |
| 初始化状态 | 未初始化 | → 已初始化 | 双入口任一先落库完成（单向，不可逆，ADR-017） |

无审批类状态流转（T3 N/A 的依据）：本域全部安全操作即时生效，无他人授权环节。

## 第七部分：查询与导出需求（T4/T5）

**审计日志查询（T4）**：筛选维度 = 时间范围（起止）、操作者（用户名）、动作类型（action：变更操作/安全事件及细分动作）、对象类型/对象标识；分页（页码/页大小）；排序默认时间倒序。无全文检索（MVP）。

**在线会话查询（T4）**：清单列 = 账户/建立时间/最后活跃时间/来源（IP/UA）；无筛选（会话量级小），按最后活跃倒序。

**审计日志导出（T5）**：范围 = 当前筛选结果全集；字段 = 审计四要素 + 记录 ID + 时间戳；格式 = **CSV（默认，假设：材料未锁定导出格式，PRD 取行业最通用格式，D3 复核）**；动作本身记审计（ADR-020）。

**被引用关系（T1a）**：审计写入接口被全部业务模块调用（R-03，OUT 边界=只定约定）；会话鉴权被 Web 终端 WS 复用（R-18）；RBAC 基线被全部页面/接口消费（ADR-018）。

## 第八部分：非功能性要求与异常场景

**N1 非功能性（已锁定项）**：二进制 <30MB、常驻内存 <60MB（idea.md §6 M1 验收标准:212）；audit_log 存储体积控制 <60MB 目标（ADR-020，90 天保留 + 每日清理达成）。未锁定项（工程化缺口，沿 knowledge 栈版本表惯例不在本阶段虚构）：登录/鉴权 QPS 指标、会话表容量上限、审计查询响应时间——D3/B 阶段按实测补齐。

**N2 异常场景**：

| 场景 | 处理 |
|------|------|
| 锁定期内登录尝试 | 拒绝并提示剩余解锁时间（R-01） |
| 双入口并发初始化 | 后到者收到「已初始化」拒绝并引导登录（ADR-017 仲裁） |
| TOTP 动态码错误 | 计一次登录失败（含在 5 次计数内） |
| CSRF 校验失败 / 同源校验失败 | 拒绝变更类请求，返回明确错误（R-02） |
| 会话过期后操作 | 引导重新登录，不静默续期 |
| 删除最后一个 admin | 拒绝并提示唯一管理员保护 |
| readonly 越界操作 | 拒绝并明确提示边界原因（ADR-018） |
| 删除/重置密码/改密后的在线会话 | 按 FR-10/11/12 立即吊销相关会话 |
| 审计写入失败 | 变更类操作整体失败（审计与业务操作同事务语义，不允许"改了但没记录"） |
| WS 握手会话无效 | 拒绝连接；已建连接在会话失效时断开（R-18） |

**N3 业务规则细节**：见第五部分规则汇总（校验规则/计算逻辑完整）。
**N4 历史需求**：审计日志即操作历史（只追加、90 天保留、导出留存）；登录/锁定/凭证变更全程留痕。
