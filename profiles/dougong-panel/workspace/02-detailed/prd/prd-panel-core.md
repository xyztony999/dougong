## 第一部分：业务目标（G1）

为斗拱面板提供全模块宿主基座：让运维者以**可审计的一键安装脚本**（每行可读，ADR-009）将**单二进制面板**（前端 go:embed 内嵌，D9）交付到存量服务器；经**四道入口面**（默认 `0.0.0.0:随机高位端口`、可选安全入口路径、可选面板域名绑定 Host 强校验（ADR-028）、HTTPS 三态「建议但不强制」且面板证书可经 ACME 签发（ADR-029），R-10）安全抵达面板；登录后在**统一外壳**（布局/路由/按角色过滤的菜单）中使用全部业务模块页面；并以 **panel_config 单例**为唯一权威治理面板自身配置（区分即时生效与需重启生效），版本可观测、更新检查**默认关闭且可完全禁用**（R-09 零外呼承诺）；另提供服务器终端 **CLI 管理通道**（`dougong` 子命令族，宝塔同款定位，ADR-030）直治面板自身（状态/信息/密码重置/端口/入口路径/服务启停）。服务对象：单机自托管的个人运维者（管理员）及其协作者（只读观察者）。

本域是运行载体与入口治理的基座：「嵌入你的服务器，而不是重装它」（产品 Slogan，idea.md §10）的交付面由本域承载；「可信」支柱的安装透明性（ADR-009）与零外呼（R-09）在本域落地。

## 第二部分：功能范围（G2）

**IN（做什么）**：

| # | 能力 | 依据 |
|---|------|------|
| 1 | 安装部署：install.sh 一键安装（下载二进制 + 生成启用 systemd unit，每行可读）、单二进制内嵌产物形态 | ADR-009、D9、idea.md §2 D9 |
| 2 | 访问接入：监听地址/端口治理（默认随机高位端口，可选仅 localhost/指定地址）、安全入口路径管控（开启后未携带者拒绝）、面板域名绑定（Host 强校验，绑定后仅该 Host 可达，ADR-028）、HTTPS 三态（关闭/自签/导入证书）、面板证书 ACME 签发与续期（HTTP-01 经已有 nginx，ADR-029）、首访 HTTPS 建议 | R-10、D0 §5、ADR-028/029 |
| 3 | 外壳呈现：布局与路由骨架、菜单按角色可见性渲染、业务模块页面挂载、认证页面承载（业务归 account-auth） | ADR-018、D1 AA 附录D |
| 4 | 配置治理：panel_config 全集维护（监听/入口/HTTPS/更新检查/语言）、即时/需重启生效分类提示、会话参数透传展示（只读） | D0 §5、D1 AA 附录C、ADR-019 |
| 5 | 版本与更新检查治理：版本信息展示、更新检查开关（默认关、可完全禁用、开启后手动触发仅版本比对提示） | R-09、idea.md §4.2 |
| 6 | CLI 管理通道：`dougong` 子命令族服务器终端本地直治面板自身——status/info/reset-password/set-port/entrypath/service 六命令族，直接操作本机数据目录/SQLite、复用进程内 service 层（无 HTTP 绕行），无面板页面 | ADR-030 |

**OUT（不做什么）**：

| # | 事项 | 归属 |
|---|------|------|
| 1 | 登录/初始化/会话/RBAC/审计业务（本域仅承载其页面路由与菜单可见性渲染） | account-auth（ADR-017~020） |
| 2 | 监控数据采集与图表 | monitoring（本域仅提供仪表盘页面框架挂载） |
| 3 | 站点 SSL 证书（ACME/自动续期） | site-mgmt（本域 HTTPS 仅面板自身证书；面板证书 ACME 经跨模块消费复用其 AcmeGateway 与 nginx 安全写回，ADR-029） |
| 4 | Web 终端连接限流 | terminal |
| 5 | 面板在线自升级（下载/替换二进制/热更新） | 非目标（idea.md §4.2：仅版本检查开关，不下载不升级） |
| 6 | 各业务功能页面本体 | 各业务模块自带（经挂载点接入） |
| 7 | DNS-01 通配符证书（面板证书 ACME 仅 HTTP-01 经 nginx 挑战） | 二期（ADR-029） |
| 8 | 独立 80 端口监听（HTTP-01 挑战复用已有 nginx 80 端口，不新增监听面） | 非目标（ADR-029：存量服务器 80 已被 nginx 占用，符合接管哲学） |

## 第三部分：角色定义（G3）

| 角色 | 英文 | 职责与权限 | 获得方式 |
|------|------|-----------|---------|
| 管理员 | admin | 面板自身设置的唯一变更者：监听/入口/域名绑定/HTTPS 与面板证书 ACME 申请·手动重试/参数/更新检查配置维护；版本与会话参数查看 | account-auth 初始化/用户管理创建 |
| 只读用户 | readonly | 按ADR-018「全可看」查看面板全部设置项当前值；禁一切变更与手动触发更新检查（ADR-018） | 管理员创建并指派 |
| 访客（未认证操作者） | — | 触达安全入口与域名绑定拦截（被拒对象）、首访 HTTPS 提示、登录/初始化页面容器；安装脚本与 CLI 管理通道执行者（服务器 SSH 终端形态，CLI 变更动作权限来自终端系统权限而非面板角色） | — |

安装脚本/systemd 治理发生在面板可用之前，操作者为服务器 SSH 运维人员（访客的终端形态，同 prd-account-auth.md 第三部分口径），无面板内入口；CLI 管理通道（FR-19，ADR-030）为运行期同一终端形态的本地治理入口，亦无面板内页面。

## 第四部分：功能需求明细

> 与 FL（function-list-panel-core.md v1.2）12 菜单行 + 6 机制型子模块一一对应；CLI 增量（v1.3）增 FR-19（S-06-04，机制型无菜单行，经 FL 附录覆盖）；异常分支统一见第八部分 N2。

### 4.1 安装部署（S-06，非面板页面：服务器终端操作）

| 编号 | 需求 | 主流程与规则 | 审计 |
|------|------|-------------|------|
| FR-01 | 安装脚本一键安装（S-06-01） | install.sh：下载二进制 → 落位文件 → 生成 dougong.service unit → 启用并启动服务；**脚本每一行可读、可人工审计**（ADR-009）；安装时生成随机高位端口写入配置 | —（面板未运行，无审计通道） |
| FR-02 | systemd 服务托管（S-06-02） | dougong.service 常驻运行、开机自启；启停治理属操作系统 systemctl，面板不提供在线自升级（idea.md §4.2） | — |
| FR-03 | 单二进制内嵌产物（S-06-03） | 前端资源 go:embed 内嵌 + SQLite 单文件存储，无运行时依赖（D9/ADR-011）；构建产物含版本标识（ldflags 注入，供 FR-15 读取） | — |
| FR-19 | CLI 管理通道（S-06-04，非面板页面：服务器终端操作） | `dougong` 子命令族（宝塔同款定位，ADR-030）**直接操作本机数据目录/SQLite，复用进程内 service 层**（单二进制优势，无 HTTP 绕行），六命令族：① `status`——systemd 状态 + 初始化态 + 访问 URL；② `info`——版本/端口/入口路径/HTTPS/数据目录；③ `reset-password -username`——管理员密码重置，环境变量注入新密码（DOUGONG_INIT_PASSWORD，同初始化口径，账户业务归 account-auth，ADR-017 同族）；④ `set-port`——端口设置（写 panel_config，同 FR-12 配置权威）；⑤ `entrypath show\|regen\|off`——安全入口路径查看/重新生成/关闭（同 FR-05 语义）；⑥ `service start\|stop\|restart\|status`——面板服务启停/重启/状态（经 systemctl 参数数组调用，R-08）。**读命令在服务运行时可直读；写命令完成后提示 `systemctl restart dougong` 生效**；裸 `dougong`（无子命令）仍=启动面板服务；无面板页面 | 写命令（reset-password/set-port/entrypath regen\|off）=变更操作（**source=cli**，R-03）；读命令与服务启停不产生面板数据变更（服务启停=systemctl OS 层治理，同 FR-02 口径） |

### 4.2 访问接入（S-07/S-08）

| 编号 | 需求 | 主流程与规则 | 审计 |
|------|------|-------------|------|
| FR-04 | 监听地址与端口治理（S-07-01） | 查看/修改监听地址与端口；默认 `0.0.0.0:随机高位端口`（安装时生成，R-10），可选仅 localhost/指定地址（listen_scope）；**保存后提示需重启服务生效**（config_effect_mode=restart_required）；服务端校验地址格式与端口范围（R-14） | 变更操作 |
| FR-05 | 安全入口路径管控（S-07-02） | 开关 + 随机生成入口路径值（可重新生成）；开启后未携带入口路径的任何访问（含未认证访客）在业务前即被拒绝；修改即时生效（R-10）。**开启后页面、脚本、图标、接口、WebSocket 全部位于入口路径之下**（构建相对地址 + 服务端注入 `<base>` + 前端统一应用基址，api D-P20；v1.7 修复「开启即白屏」缺陷，使实现回归本意图）；设置页开启 / 重新生成 / 关闭成功后整页跳转到新地址（不在旧基址页面上继续请求），路径展示框跨跳转保留（N2 遗忘风险对策） | 变更操作 |
| FR-06 | HTTPS 三态配置（S-08-01） | off/self_signed/imported 三态：自签由系统生成证书；导入需上传证书与私钥（服务端校验配对性，失败拒绝保存，R-14）；除关闭外即时生效；**建议但不强制**（R-10） | 变更操作 |
| FR-07 | 首访 HTTPS 建议（S-08-02） | 以 HTTP 方式访问时展示建议启用 HTTPS 提示；设置页常驻 HTTPS 开关——「建议但不强制」统一口径（R-10） | — |
| FR-17 | 面板域名绑定（S-07-03，菜单「域名绑定设置」） | 查看/维护 panel_config.bind_domain（可空=未绑定）；绑定后仅该域名的 Host 可访问面板，IP 直连与其他 Host 的一律返回**标准 404**（防探测，与安全入口路径同语义，无业务错误码包裹）；校验态读取失败按 fail-closed 拒绝；绑定/解绑即时生效（ADR-028）；域名格式服务端校验（R-14，匹配口径见待对齐-7） | 变更操作 |
| FR-18 | 面板证书 ACME 签发与续期（S-08-03，菜单「ACME 证书设置」） | 面板自身证书 ACME 申请：HTTP-01 挑战经服务器**已有 nginx** 完成——挑战 location 临时注入/撤除与签发通道复用 site-mgmt AcmeGateway（lego ACL）与 nginx 安全写回（R-06 备份→临时注入 /.well-known/acme-challenge location→签发→撤除→`nginx -t`→失败回滚保障，ADR-029 跨模块消费契约），**不新增独立 80 端口监听**；证书落 panel_cert（source 扩展 acme）；HTTPS 模式联动（取值扩展形态见待对齐-6）；到期前自动续期、失败手动重试，状态沿用 ADR-024 六状态语义按需简化引用（valid/expiring_soon/renew_failed/expired 主路径）；证书概要（来源/签发者/有效期/上次失败原因）查看；DNS-01 二期 | 申请/手动重试=变更操作；自动续期=系统动作（均记审计，R-03） |

### 4.3 外壳呈现（S-09/S-10，机制型系统需求）

| 编号 | 需求 | 主流程与规则 | 审计 |
|------|------|-------------|------|
| FR-08 | 布局与路由骨架（S-09-01） | 前端整体布局与路由注册：认证页面路由（登录/初始化向导）与全部业务页面路由的统一容器。页面切换过程可见：切换开始即有加载反馈（被点击的菜单项立即高亮，超过 200ms 未完成时顶栏显示「正在加载页面…」）；切换失败可恢复：网络原因给出提示、下一次点击重试，面板升级后未刷新的旧页面自动重新加载一次（同一目标 30 秒内至多一次）；弹窗、抽屉正在关闭时，落在侧栏上的点击照常生效，落在页面其它位置的点击仍被拦住；内嵌页面文件压缩传输，已不存在的文件回标准 404（api D-P19；v1.6） | — |

## 第六部分：状态流转（T2）

**本域无生命周期状态机**（D0 拍板：配置为单例资源，变更即生效/提示重启项）。辨析：

| 易混淆项 | 辨析 | 结论 |
|---------|------|------|
| HTTPS 模式 off/self_signed/imported | 模式枚举（可任意切换），无生命周期单向性 | 非状态机，属配置字段 |
| 面板证书 ACME 状态（acme 来源） | 单例证书对象上的签发/续期结果语义，**沿用 ADR-024 六状态语义按需简化引用**（valid/expiring_soon/renew_failed/expired 主路径）；非多实例证书生命周期状态机（对照 site-mgmt certificate 聚合根） | 非状态机聚合，简化状态标注（字段形态 D3 定，待对齐-6） |
| 安全入口开关 / 更新检查开关 {off,on} | 布尔开关，即时切换无流转路径 | 非状态机，属配置字段 |
| 「待重启」标识 | 保存动作的派生提示态（重启后消失），非持久化生命周期 | 派生展示态（过程数据） |
| 外壳对访客/只读/管理员的可达范围 | 由 account-auth 会话与 RBAC 判定驱动 | 判定结果消费，本域无状态 |
| CLI 管理通道命令族（FR-19） | 六命令族均为无状态单发动作（读/写/服务控制），命令间无流转路径；其变更结果落既有聚合（panel_config/panel_user） | 非状态机，终端工具行为 |

无审批类状态流转（T3 N/A 的依据）：本域全部配置操作管理员即时生效，无他人授权环节。

## 第八部分：非功能性要求与异常场景

**N1 非功能性（已锁定项）**：二进制 <30MB、常驻内存 <60MB（idea.md §6 M1 验收标准:212；v1.6 口径补充：内嵌页面文件的 gzip 压缩缓存按需驻留内存、计入该预算——全部可压缩文件都被访问到时上限约 4.3MB，访问过全部侧栏页面但不开在线编辑器时约 0.6MB（Monaco 内核与语言 worker 约占上限的 3.1MB），api D-P19）；SQLite 单文件存储（ADR-011）；安装脚本行数可读性（ADR-009，无压缩混淆）；CLI 管理通道（ADR-030，v1.3 增）——① **读命令服务运行时可执行**（status/info/entrypath show/service status 在面板服务运行时可直接读取，不要求停服）；② **写命令完成后提示 `systemctl restart dougong` 生效**；③ CLI 变更审计 **source=cli**（枚举池既有 audit_source）。未锁定项（工程化缺口，不虚构，D3/B 阶段补齐）：更新检查外呼超时上限与重试策略、导入证书大小上限、自签证书有效期（行业惯例 10 年，待复核）、入口路径长度与字符集、CLI 子命令输出字段形态与并发写仲裁（待对齐-8）。

**N2 异常场景**：

| 场景 | 处理 |
|------|------|
| 修改监听端口后未重启 | 设置页持续显示「待重启生效」标识（FR-13），不静默生效 |
| 重启后端口被占用 | systemd 启动失败，面板不可达；排查路径=systemctl status（FR-02，OS 层治理），无面板内自修复 |
| 安全入口路径开启后遗忘 | 面板不可达；恢复机制未锁定（候选：CLI 重置/本地配置编辑），见第九部分待对齐 |
| 导入证书与私钥不配对/格式错误 | 服务端校验失败拒绝保存（R-14），原 HTTPS 配置保留不变 |
| HTTPS 模式切换为导入但未上传证书 | 拒绝保存并提示需上传证书与私钥（R-14） |
| 更新检查外呼失败/超时 | 提示检查失败原因；不自动重试轰炸（R-09 克制原则），面板功能不受影响 |
| readonly 尝试变更配置/触发更新检查 | 拒绝并明确提示边界原因（ADR-018，经 account-auth 访问控制执行） |
| 配置保存写入失败 | 保存整体失败返回错误，panel_config 保持原值（不允许半写） |
| 携带错误入口路径访问 | 与未携带同等待遇：拒绝（不泄露路径存在性） |
| 未携带入口路径访问且开关关闭 | 正常放行至认证页/业务路由（开关默认 off） |
| 绑定域名后以 IP 或其他 Host 访问 | 一律标准 404（防探测，无业务错误码包裹，ADR-028） |
| 域名绑定校验态读取失败 | fail-closed：按拒绝处理（404），不放大可访问面（沿只读依赖失败即拒先例，ADR-028） |
| nginx 未检出/80 端口未由 nginx 监听 | 面板证书 ACME 申请与续期前置拒绝并如实提示（HTTP-01 挑战通道不可用；语义对齐 site-mgmt nginx 空态先例 SITE_012） |
| ACME 申请/续期失败（挑战不通/CA 拒绝/超时） | 证书保持原状并标注失败原因（renew_failed 语义，ADR-024 简化引用），可手动重试；不自动无限重试（沿 site-mgmt D-09 每日单次调度口径） |
| CLI 写命令完成后未按提示重启服务 | 命令结果已落库（panel_config/panel_user）；CLI 输出统一提示 `systemctl restart dougong`（ADR-030），未重启前运行中面板行为以各配置项生效分类为准（即时项生效、重启项置待重启标识，FR-13/D1 AA 附录C） |
| 页面切换耗时较长（慢链路上首次打开某页面） | 切换开始即有加载反馈（菜单项立即高亮、超过 200ms 顶栏显示「正在加载页面…」），不出现「点了没反应」；连点以最后一次为准（v1.6，FR-08） |
| 页面文件（分包）因网络原因没下载下来 | 界面留在原页面并提示「页面没加载出来。请检查网络后再点一次」；不自动重新加载；下一次点击自动重试（v1.6，FR-08） |
| 面板升级后，未刷新的旧页面请求已不存在的页面文件 | 服务器对该文件回标准 404（D-P19）；前端识别后自动重新加载并打开目标页面，同一目标 30 秒内至多一次（防循环），重新加载后提示「面板已更新，页面已重新打开」；自动重新加载后仍失败或 30 秒内已自动重新加载过 → 弹出提示框「面板已更新，请刷新页面。」并提供「刷新页面」按钮（v1.6，FR-08） |
| 页面内的按需模块没下载下来（如在线编辑器） | 与分包网络失败 / 面板已升级两条同规则；这种情况自动重新加载的是当前页面地址（v1.6，FR-08） |
| 其它导航错误（非页面文件加载失败） | 提示「页面打开出错。请刷新后重试」，不自动重新加载（v1.6，FR-08） |
| 入口脚本探测请求本身失败（网络不通），或探测拿到 404 以外的非成功状态码（反向代理的 5xx、不支持 HEAD 的 405 等） | 按网络原因处理（提示后再点重试），不误判为面板已升级、不自动重新加载（v1.6，FR-08；口径于 2026-11-24 验收时收紧） |
| 升级前就已打开的页面，且来自不含本规则的旧版本 | 不适用「面板已升级」的自动处理：页面跑的是旧代码，需手动刷新一次；此后再升级才自动处理（v1.6，2026-11-24 验收时补记） |

**N3 业务规则细节**：见第五部分规则汇总（生效分类全集=D1 AA 附录C：9 配置项逐项标注默认值/生效方式/备注）。
**N4 历史需求**：配置变更历史由 audit_log 承载（R-03：谁/何时/改了什么/结果，本域经 OHS 写入），本域不另设配置历史表；90 天保留与导出治理归 account-auth（ADR-020）。
