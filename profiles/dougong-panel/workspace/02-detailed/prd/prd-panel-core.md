## 第一部分：业务目标（G1）

为斗拱面板提供全模块宿主基座：让运维者以**可审计的一键安装脚本**（每行可读，ADR-009）将**单二进制面板**（前端 go:embed 内嵌，D9）交付到存量服务器；经**三道入口面**（默认 `0.0.0.0:随机高位端口`、可选安全入口路径、HTTPS 三态「建议但不强制」，R-10）安全抵达面板；登录后在**统一外壳**（布局/路由/按角色过滤的菜单）中使用全部业务模块页面；并以 **panel_config 单例**为唯一权威治理面板自身配置（区分即时生效与需重启生效），版本可观测、更新检查**默认关闭且可完全禁用**（R-09 零外呼承诺）。服务对象：单机自托管的个人运维者（管理员）及其协作者（只读观察者）。

本域是运行载体与入口治理的基座：「嵌入你的服务器，而不是重装它」（产品 Slogan，idea.md §10）的交付面由本域承载；「可信」支柱的安装透明性（ADR-009）与零外呼（R-09）在本域落地。

## 第二部分：功能范围（G2）

**IN（做什么）**：

| # | 能力 | 依据 |
|---|------|------|
| 1 | 安装部署：install.sh 一键安装（下载二进制 + 生成启用 systemd unit，每行可读）、单二进制内嵌产物形态 | ADR-009、D9、idea.md §2 D9 |
| 2 | 访问接入：监听地址/端口治理（默认随机高位端口，可选仅 localhost/指定地址）、安全入口路径管控（开启后未携带者拒绝）、HTTPS 三态（关闭/自签/导入证书）、首访 HTTPS 建议 | R-10、D0 §5 |
| 3 | 外壳呈现：布局与路由骨架、菜单按角色可见性渲染、业务模块页面挂载、认证页面承载（业务归 account-auth） | ADR-018、D1 AA 附录D |
| 4 | 配置治理：panel_config 全集维护（监听/入口/HTTPS/更新检查/语言）、即时/需重启生效分类提示、会话参数透传展示（只读） | D0 §5、D1 AA 附录C、ADR-019 |
| 5 | 版本与更新检查治理：版本信息展示、更新检查开关（默认关、可完全禁用、开启后手动触发仅版本比对提示） | R-09、idea.md §4.2 |

**OUT（不做什么）**：

| # | 事项 | 归属 |
|---|------|------|
| 1 | 登录/初始化/会话/RBAC/审计业务（本域仅承载其页面路由与菜单可见性渲染） | account-auth（ADR-017~020） |
| 2 | 监控数据采集与图表 | monitoring（本域仅提供仪表盘页面框架挂载） |
| 3 | 站点 SSL 证书（ACME/自动续期） | site-mgmt（本域 HTTPS 仅面板自身证书） |
| 4 | Web 终端连接限流 | terminal |
| 5 | 面板在线自升级（下载/替换二进制/热更新） | 非目标（idea.md §4.2：仅版本检查开关，不下载不升级） |
| 6 | 各业务功能页面本体 | 各业务模块自带（经挂载点接入） |

## 第六部分：状态流转（T2）

**本域无生命周期状态机**（D0 拍板：配置为单例资源，变更即生效/提示重启项）。辨析：

| 易混淆项 | 辨析 | 结论 |
|---------|------|------|
| HTTPS 模式 off/self_signed/imported | 模式枚举（可任意切换），无生命周期单向性 | 非状态机，属配置字段 |
| 安全入口开关 / 更新检查开关 {off,on} | 布尔开关，即时切换无流转路径 | 非状态机，属配置字段 |
| 「待重启」标识 | 保存动作的派生提示态（重启后消失），非持久化生命周期 | 派生展示态（过程数据） |
| 外壳对访客/只读/管理员的可达范围 | 由 account-auth 会话与 RBAC 判定驱动 | 判定结果消费，本域无状态 |

无审批类状态流转（T3 N/A 的依据）：本域全部配置操作管理员即时生效，无他人授权环节。

## 第七部分：查询与导出需求（T4/T5）

**查询（T4）**：本域无台账列表。配置读取为**单例读**（一次返回 panel_config 全集），无筛选/分页/排序维度；版本信息为单点只读展示。

**导出（T5）**：无导出需求（配置不留存导出；审计导出归 account-auth FR-20）。

**被引用关系（T1a）**：

| 被引用能力 | 消费方 | 方式 |
|-----------|--------|------|
| 外壳挂载点（FR-10） | 全部业务模块 | 子路由/菜单项接入登记（D1 AA 附录D） |
| 全局入口拦截（FR-05） | 全部业务模块路由 | 被动前置网关（含未认证访问） |
| panel_config 配置源 | 本域入口面模块（S-07/S-08/S-12）与设置页 | 唯一读写入口 FR-12 |

## 第八部分：非功能性要求与异常场景

**N1 非功能性（已锁定项）**：二进制 <30MB、常驻内存 <60MB（idea.md §6 M1 验收标准:212）；SQLite 单文件存储（ADR-011）；安装脚本行数可读性（ADR-009，无压缩混淆）。未锁定项（工程化缺口，不虚构，D3/B 阶段补齐）：更新检查外呼超时上限与重试策略、导入证书大小上限、自签证书有效期（行业惯例 10 年，待复核）、入口路径长度与字符集。

**N2 异常场景**：

| 场景 | 处理 |
|------|------|
| 修改监听端口后未重启 | 设置页持续显示「待重启生效」标识（FR-13），不静默生效 |
| 重启后端口被占用 | systemd 启动失败，面板不可达；排查路径=systemctl status（FR-02，OS 层治理），无面板内自修复 |
| 安全入口路径开启后遗忘 | 面板不可达；恢复机制未锁定（候选：CLI 重置/本地配置编辑），见第九部分待对齐 |
| 导入证书与私钥不配对/格式错误 | 服务端校验失败拒绝保存（R-14），原 HTTPS 配置保留不变 |
| HTTPS 模式切换为导入但未上传证书 | 拒绝保存并提示需上传证书与私钥（R-14） |
| 更新检查外呼失败/超时 | 提示检查失败原因；不自动重试轰炸（R-09 克制原则），面板功能不受影响 |
| readonly 尝试变更配置/触发更新检查 | 拒绝并明确提示边界原因（ADR-018，经 account-auth 访问控制执行） |
| 配置保存写入失败 | 保存整体失败返回错误，panel_config 保持原值（不允许半写） |
| 携带错误入口路径访问 | 与未携带同等待遇：拒绝（不泄露路径存在性） |
| 未携带入口路径访问且开关关闭 | 正常放行至认证页/业务路由（开关默认 off） |

**N3 业务规则细节**：见第五部分规则汇总（生效分类全集=D1 AA 附录C：9 配置项逐项标注默认值/生效方式/备注）。
**N4 历史需求**：配置变更历史由 audit_log 承载（R-03：谁/何时/改了什么/结果，本域经 OHS 写入），本域不另设配置历史表；90 天保留与导出治理归 account-auth（ADR-020）。

## 附录：PRD 完备性检查报告

**功能类型**：主数据（配置单例管理）型——panel_config 为单例主数据，无状态机、无台账、无审批、无导出；附一次性部署流程（安装，非面板页面）与单动作工具行为（更新检查手动触发）。
